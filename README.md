# Chat App

A real-time chat application built with React (frontend) and Node.js (backend) using WebSockets for instant messaging.

## Project Structure

- **client/**: React frontend with Vite
- **server/**: Express backend with Socket.io and MongoDB

## Features

- User authentication (Register/Login)
- Real-time messaging
- User profiles
- Online status tracking

## Getting Started

See individual README files in client/ and server/ folders for setup instructions.
